## 앞선 기획서에서 이어 쓴 노트

재미 심리, 리텐션·이탈, 수익화·규제, 소셜, 시장 사례, 행동 설계(A~F)는 앞선 기획서 때 정리한 노트를 이 기획서에도 썼다. 파일은 [../../game-design/research/](../../game-design/research/README.md)에 있다.

## 검증 표시

- **yes**: 데이터를 낸 곳의 원문(보고서, 논문, 공식 페이지)을 직접 읽고 수치를 확인했다.
- **partial**: 일부만 확인했다. 초록이나 메타데이터만 읽었거나, 수치 일부를 2차 자료에서 가져왔다. 항목마다 어느 부분인지 적었다.
- **secondary**: 다른 회사의 데이터를 전하는 기사나 요약 페이지를 읽었다. 원 보고서는 유료이거나 공개되지 않았다.
- **derived**: 공개된 수치로 직접 계산한 값이다. 계산 방법을 함께 적었다.
- **chart-read**: 그래프에서 읽은 값이다.

시장 수치는 제공사마다 정의가 다르다. 총매출과 순매출, 집계하는 스토어와 국가 범위가 다르므로 한 비교 안에서는 한 제공사의 수치만 썼다. 효과 크기는 대부분 다른 게임과 다른 맥락에서 나온 값이므로, 기획서 16장(데이터·실험 계획)처럼 우리 게임의 데이터로 다시 확인해야 한다.
